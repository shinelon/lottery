# 项目背景与当前结论

## 需求沿革（对话摘要）

| 环节 | 结论 |
|---|---|
| 初始诉求 | 依据往期中奖记录「预估」下一期号码 |
| 定位修正 | 每期独立同分布，无法预测；改为「统计筛选 + 组合设计 + 严格复盘」 |
| 数据来源 | 中彩网官方接口（已选定），500彩票网为备用源 |
| 样本范围 | 近 100 期（2026024 – 2026123），另抓 260 期做特征预热 |
| 投注方式 | 每期 5 注单式，10 元；不做复式、不做胆拖 |
| 回测切分 | 前 60 期定规则 / 后 40 期盲测（2026084 – 2026123） |
| 交付形态 | 每期 Markdown 报告 + 可复跑 Python 脚本，纯标准库 |
| 依赖 | 不装 pandas/requests。抓取用系统 `curl.exe`，urllib 兜底 |

## 方法（都已固化在 ssq.py）

1. **特征**（严格只用当期之前的数据）
   - 红球：近 50 期频次分位、当前遗漏、遗漏回归值（靠近历史中段加权）
   - 蓝球：近 30 期频次分位 + 遗漏回归值
2. **打分**：`0.6 × 频次分位 + 0.4 × 遗漏回归值`，只有这一组权重，不做网格搜索
3. **形态过滤**：和值 90–120、奇偶 2:4–4:2、三区（1–11/12–22/23–33）不空区、
   与上期重号 0–2、排除三连号
4. **组注**：从高分池枚举候选组合，取 5 注，约束两两红球重合 ≤2、形态不重复
5. **蓝球分配**：取最高分 2 个候选，按 3:2 分给 5 注
6. **验证三层**：5000 次蒙特卡洛 + 9 个滚动窗口（步长 20、长度 40）+ 20 组参数敏感性

## 关键数字（2026124 期这一版）

| 指标 | 值 | 参照 |
|---|---|---|
| 盲测注数 | 200 注 / 400 元 | 40 期 × 5 注 |
| 蓝球命中 | 28 次 | 期望 12.5，结构一致 1σ≈5.3 |
| 蓝球百分位 | 99.7 | 超出单次 3σ |
| 红球≥3 | 11 次 | 期望 11.6，1σ≈3.3 → 无差异 |
| 红球≥4 | 0 次 | 期望约 1.0 |
| 回款 | 150 元 | 回报率 37.5% |
| 中奖分布 | 六等奖 ×26，五等奖 ×2 | — |
| 滚动窗口跑赢 | 4 / 9 | 不构成稳定复现 |
| 参数敏感性 | 8 – 28（中位 14） | 当前配置恰在最高点 |

## 当前结论

**当前规则不具备可信的预测能力。** 蓝球那 28 次是窗口运气：换窗口只剩 4/9 跑赢，
微调参数就在 8–28 间摆动，且独立重算可掉到 20。红球侧与随机完全无差异，
符合理论预期。

价值不在号码，而在这套**可复现、可证伪**的记录方式。样本累积到 300 期以上再回看。

## 文件职责

| 路径 | 作用 |
|---|---|
| `ssq.py` | 抓取 → 清洗 → 特征 → 选号 → 回测 → 报告，单命令全流程 |
