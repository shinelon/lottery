# 踩坑记录（大乐透，改代码前先读）

这五条是大乐透与双色球**不一样**的地方，照抄双色球实现就会错。

## 1. 奖级表已换（2026-01-31 起）

**现象**：照旧资料写「九等奖、三等 10,000、四等 3,000」，跑出来的奖金全错。

**正确规则**：13 个中奖条件不变，9 奖级合并为 **7 奖级**：
一等 5+2、二等 5+1、三等 5+0 或 4+2、四等 4+1、
五等 4+0 或 3+2、六等 3+1 或 2+2、七等 3+0 或 2+1 或 1+2 或 0+2。

固定奖分两档：奖池 <8 亿时 5000 / 300 / 150 / 15 / 5，≥8 亿时 6666 / 380 / 200 / 18 / 7。
`prize_table(pool)` 按当期奖池选档，别写死一档。

## 2. 期号是 5 位，不是 7 位

双色球 `2026124`，大乐透是 `26124`（年份 2 位 + 序号 3 位）。
校验、排序、CSV、目标期推算全部按 5 位处理；跨年时是 `27001`，不是 `26200`。

## 3. 停售 21:00、开奖 21:25（不是 20:00）

2023-01-01 起体彩把止售从 20:00 延到 21:00、开奖延到 21:25。
`SALE_CUTOFF_HOUR = 21`，开奖日 `{0, 2, 5}`（周一/三/六）。
双色球的 20:00 与 `{1, 3, 6}` 不能直接搬过来。

## 4. 后区是 12 选 2，零分布要按 3 个号 2/2/1 构造

**现象**：一旦 5 注共享后区号码，后区命中总数的方差会明显大于「5 注各自随机」。

**数据**：5000 次模拟，结构一致零分布 1σ≈12.5，独立零分布 1σ≈7.1。
用独立基准衡量，会把正常波动当成优势（这次 74 次在独立基准下是第 86.5 百分位，
在结构一致基准下只有第 75.0）。

**修法**：`monte_carlo()` 同时产出 `back_ind` 与 `back_match`，**判定只认 `back_match`**。
与双色球「2 蓝 3:2」是同一类陷阱，但参数不同，不能复用代码。

## 5. 前区 ≥3 的计数太小，别用它下结论

200 注里「前区命中 ≥3」的期望只有 **2.8 次**，观测到 0 或 5 都说明不了问题。
判定用**前区命中总数**（期望 142.9，1σ≈10.4），它才是有效统计量。
「后区两个全中」期望 3.0 次，同样只作参考。

## 附带教训

- 回测只折算固定奖；一、二等奖金额浮动，按 0 计，所以回报率天然偏低（本次 15%），
  不代表方案比随机差，也不代表好。
- 奖级概率必须回到 `C(35,5)×C(12,2)=21,425,712` 现算，报告里的概率表由 `tier_counts()` 生成。
- 体彩接口每页最多 100 期，抓 260 期要翻 3 页；返回值是**新到旧**，先截断再排序。
- 控制台是 GBK，中文输出要 `PYTHONIOENCODING=utf-8`，写文件统一 `utf-8`（CSV 用 `utf-8-sig`）。
