# 超级大乐透分析与选号

## 何时使用

- 「跑一下大乐透」「出下一期大乐透号码」「拉最新大乐透开奖」
- 「上期中了吗」「复盘一下」「回测结果怎么样」
- 用户提到大乐透、前区后区、35 选 5、12 选 2、选号、走势

## 前置条件

- 项目根目录存在 `dlt.py`（纯标准库，Python 3.10+；本机命令是 `py`）
- `data/` 与 `reports/` 与 `dlt.py` 同级，脚本会自动创建（`reports/dlt/`）
- 抓取优先走系统 `curl.exe`，`urllib` 兜底。本机 urllib 的 TLS 请求会被网络层拦截，属正常现象
- 与双色球工具 `ssq.py` 完全独立：数据、报告、记录分开放，互不覆盖

## 执行流程

1. **定位根目录**：`SKILL.md` 位于 `.dsh/skills/dlt-lottery/`，脚本在 `../../../dlt.py`。
2. **运行**（在项目根目录）：

   ```powershell
   $env:PYTHONIOENCODING="utf-8"
   py dlt.py              # 联网抓 260 期 -> 分析近 100 期 -> 出下一期 5 注
   ```

   离线或抓取失败时：`py dlt.py --no-fetch`（用 `data/dlt.csv` 缓存）。
   调整窗口：`py dlt.py --window 120 --test-n 40`。

3. **读取产物**：`reports/dlt/<目标期号>.md`。向用户复述时包含：
   - 目标期号与日期、注数与成本、当期奖池档位
   - 5 注前区后区（表格，号码已排序、补零两位）
   - 盲测结论：后区命中总数/百分位、前区命中总数/百分位、各自判定
   - 稳健性：滚动窗口跑赢个数（n/9）、参数敏感性区间、中奖注数与回款
4. **只问号码时**给表；**问「准不准」时必须连结论段一起给**，不能只报命中数。
5. **复盘**：再次运行会自动把上期实际开奖回填到 `reports/dlt/history.csv`，按期号+注号去重，重复运行安全。
6. **目标期推算**：接口最新期号 +1；周一/周三/周六开奖，当天 21:00 后顺延到下一个开奖日。
   期号是 **5 位**（年份 2 位 + 序号 3 位，如 `26124`），不是双色球的 7 位。

## 规则口径（2026-01-31 第 26014 期起的新规则）

- 前区 35 选 5 + 后区 12 选 2，单注 2 元；本工具不做追加（追加仅参与浮动奖，80%）。
- 9 个奖级已合并为 **7 个**，13 个中奖条件不变：

  | 奖级 | 条件 | 单注奖金（奖池<8亿 / ≥8亿） |
  |---|---|---|
  | 一等 | 5 前 + 2 后 | 浮动 / 浮动（单注上限 500 万） |
  | 二等 | 5 前 + 1 后 | 浮动 / 浮动（单注上限 500 万） |
  | 三等 | 5 前、4 前 + 2 后 | 5,000 / 6,666 |
  | 四等 | 4 前 + 1 后 | 300 / 380 |
  | 五等 | 4 前、3 前 + 2 后 | 150 / 200 |
  | 六等 | 3 前 + 1 后、2 前 + 2 后 | 15 / 18 |
  | 七等 | 3 前、2 前 + 1 后、1 前 + 2 后、2 后 | 5 / 7 |

- 单注概率（分母 C(35,5)×C(12,2) = 21,425,712）：
  一等 1/21,425,712；二等 1/1,071,286；三等 1/109,875；四等 1/7,142；
  五等 1/1,930；六等 1/168；七等 1/16.6；任意奖约 6.67%（1/15）。
- 返奖率 **51%**（其中 49% 当期奖金 + 2% 调节基金；发行费 13%、公益金 36%）。
  一、二等奖占大头且单期总额上限 1 亿元，短样本必然碰不到。

## 判定口径（不可简化）

- 后区零分布必须用**结构一致**的那种：每期随机 3 个后区号、按 2/2/1 组 5 对，1σ≈12.5。
  不能用「200 注各自随机后区」（1σ≈7.1），否则会把注间相关带来的方差误判成优势。
- **单次跳出 ≠ 有效**。必须同时满足：滚动窗口多数跑赢 + 参数微调后优势仍在。
  当前项目三项证据一致指向「与随机无差异」，不要改写成正面结论。
- 前区样本功效有限：200 注里「前区≥3」期望只有 2.8 次，判定要看**前区命中总数**
  （期望 142.9，1σ≈10.4），不要拿 2.8 这种小计数下结论。
- 回测只折算固定奖；浮动奖金额未知，按 0 计，因此回报率天然偏低（本次 15%），
  **不能用「没回本」否定方案，也不能用「后区蒙对」肯定方案**。

## 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 接口 state/errorCode 异常 | 体彩接口变动或限流 | 重试；脚本会自动退到 500 彩票网，再退到本地缓存 |
| HTTP 403 / SSL EOF | urllib 被网络层拦截 | 确认 `curl.exe` 可用；脚本已优先用 curl |
| 数据不足 | 缓存期数 < window+10 | 联网重抓，或减小 `--window` |
| 形态过滤后无候选组合 | 和值/奇偶/三区约束过紧 | 放宽 `form_ok` 里的和值区间（当前 70–110） |
| 报告期号不是预期 | 已过 21:00 停售 | 正常，顺延到下一个开奖日（周一/三/六） |
