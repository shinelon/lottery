# 双色球 / 大乐透 分析与选号工具

两套独立的流水线，流程相同、数据与产物分开：`ssq.py`（双色球）与 `dlt.py`（超级大乐透）。

按「历史数据 → 特征 → 选号 → 盲测 → 复盘」的流程，每期生成 5 注单式和一份分析报告。

**先看这句**：两种玩法都是每期独立同分布，任何基于历史号码的筛选都**不改变**单注中奖概率
（双色球 1/17,721,088、返奖率约 50%；大乐透 1/21,425,712、返奖率 51%）。本工具的
价值是「可复现的记录与诚实的自我检验」，不是预测。仓库里各报告第四部分就是这套检验
本身的结论。

## 环境

- Windows + Python 3.10 以上（本机 `py` = 3.15）
- **零第三方依赖**，只用标准库
- 抓取优先调用系统 `curl.exe`（本机 urllib 的 TLS 请求会被网络层拦截），
  urllib 作为兜底

## 用法

```powershell
py ssq.py                # 抓取最新数据 -> 回测 -> 出下一期 5 注 + 报告
py ssq.py --no-fetch     # 只用本地 data/ssq.csv（离线/复跑）
py ssq.py --window 120 --test-n 40   # 改分析窗口与盲测期数
```

目标期号自动推算：取接口最新期号 +1，并按周二/周四/周日、20:00 停售时间顺延。

## 输出

| 路径 | 内容 |
|---|---|
| `data/ssq.csv` | 历史开奖（期号/日期/6 红/蓝/销量/奖池），260 期滚动 |
| `reports/YYYYNNN.md` | 当期报告：5 注单式、每注理由、覆盖度、回测与稳健性结论 |
| `reports/history.csv` | 累计记录，下期运行自动回填实际开奖与命中 |

## 大乐透（dlt.py）

与双色球同构：前区 35 选 5、后区 12 选 2，单注 2 元，每期 5 注；前 60 期定规则 /
后 40 期盲测，5000 次蒙特卡洛 + 9 个滚动窗口 + 20 组参数敏感性。

```powershell
py dlt.py                # 抓最新数据 -> 回测 -> 出下一期 5 注 + 报告
py dlt.py --no-fetch     # 只用本地 data/dlt.csv（离线/复跑）
```

| 路径 | 内容 |
|---|---|
| `data/dlt.csv` | 历史开奖（期号/日期/前区 5/后区 2/销量/奖池），260 期滚动 |
| `reports/dlt/<期号>.md` | 当期报告：注单、每注理由、覆盖度、回测、稳健性、概率表 |
| `reports/dlt/history.csv` | 累计记录，下期自动回填命中与奖金 |

差异点（照抄双色球会出错）：

- 期号是 **5 位**（`26124`），不是 7 位；
- 开奖 **周一/三/六 21:25**，当期销售截止 **21:00**；
- 2026-01-31（第 26014 期）起奖级由 9 个合并为 **7 个**，固定奖分奖池 <8 亿 / ≥8 亿两档；
- 单注概率：一等 1/21,425,712，二等 1/1,071,286，三等 1/109,875，七等 1/16.6，任意奖 6.67%；
- 返奖率 51%，其中一、二等奖占大头；回测只折算固定奖，所以回报率天然偏低。

## 方法

1. **特征**（只用在当期之前的数据）
   - 红球：近 50 期频次分位、当前遗漏、遗漏回归值（靠近历史中段加权）
   - 蓝球：近 30 期频次分位 + 遗漏回归值
2. **打分**：`0.6 × 频次分位 + 0.4 × 遗漏回归值`，只有这一组权重，不做网格搜索
3. **形态过滤**：和值 90–120、奇偶 2:4–4:2、三区不空、与上期重号 0–2、排除三连号
4. **组注**：从高分池枚举候选，取 5 注，约束两两重合 ≤2、形态不重复
5. **验证**：前 60 期定规则 / 后 40 期盲测 + 5000 次蒙特卡洛 + 9 个滚动窗口 + 20 组参数敏感性

## 关于「优势」的判定

- 蓝球基准要分两种：每期随机 2 蓝 3:2（结构一致，1σ≈5.3）与 200 注各自随机（1σ≈3.4）。
  用错基准会把方差当成优势。
- 单次盲测跳出 3σ **不算**证明；还要看滚动窗口能否复现、参数微调后是否还成立。
- `reports/2026124.md` 的实际结论：三项证据互相矛盾，判定为**无预测能力**。

## 常见问题

**为什么回报率只有 30% 多？** 双色球返奖率 50%，其中约 17%–25% 压在一等奖上，
短样本碰不到，所以实测必然偏低。评价要看命中分布，不是看回本。

**能改成别的期数/注数吗？** 期数用 `--window`；注数改 `TICKETS`（默认 5）。

**数据更新失败？** 先确认 `curl.exe` 可用；仍失败时可用 `--no-fetch` 跑缓存。
